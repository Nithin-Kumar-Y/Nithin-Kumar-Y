## 🏆 Featured Project

### 🎮 NETHRA — Life-RPG

A gamified life-tracking web application that transforms real-world activities into RPG-style quests.

**Features:**
- ⚔️ Real-world activities converted into quests
- ⭐ XP, Gold, Levels and Character Progression
- 🧠 Intellect, Strength & Discipline attributes
- 🔥 Daily streaks and achievements
- 📅 Calendar-based activity tracking
- 🎒 Inventory and in-game shop
- 🎲 Mini-games
- 🌅 Dynamic Morning / Evening / Night themes
- 👤 Character and profile progression
- 📱 Responsive interface

**Tech Stack:**  
`Next.js` `React` `TypeScript` `Tailwind CSS` `Supabase`
